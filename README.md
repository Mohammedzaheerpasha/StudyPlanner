# StudyPlanner

## Project Description

This repository contains the source code for StudyPlanner, a project designed to help users organize and manage their study schedules effectively.

## Key Features & Benefits

*   **Schedule Creation:** Allows users to create detailed study schedules.
*   **Task Management:** Enables the addition, modification, and deletion of study tasks.
*   **Progress Tracking:** Provides tools to monitor progress on assigned tasks.
*   **Notifications/Reminders:** (Future implementation) Sends reminders for upcoming tasks.
*   **User-Friendly Interface:** Offers an intuitive interface for ease of use.

## Prerequisites & Dependencies

Before you can run this project, ensure you have the following installed:

*   **Java Development Kit (JDK):** Version 8 or higher.
*   **Android SDK:** Necessary for building and running the Android application.
*   **Android Studio:** (Recommended) Or another compatible IDE for Android development.
*   **Kotlin:** (If the project uses Kotlin beyond the base code) the Kotlin plugin in Android Studio.
*   **Gradle:** Version appropriate for the Android Gradle Plugin version used in the project. (Typically bundled with Android Studio).

## Installation & Setup Instructions

Follow these steps to install and set up the project:

1.  **Clone the Repository:**
    ```bash
    git clone https://github.com/FidaHuss786/StudyPlanner.git
    cd StudyPlanner
    ```

2.  **Open in Android Studio:**
    *   Launch Android Studio.
    *   Select "Open an Existing Project".
    *   Navigate to the cloned `StudyPlanner` directory and select it.

3.  **Gradle Sync:**
    *   Android Studio will automatically start Gradle Sync. If it doesn't, manually trigger it by selecting `File > Sync Project with Gradle Files`.
    *   Resolve any dependency issues that may arise during the sync process.

4.  **Build the Project:**
    *   Go to `Build > Make Project`.

5.  **Run the Application:**
    *   Connect an Android device or start an emulator.
    *   Click the "Run" button in Android Studio to deploy and run the application.
